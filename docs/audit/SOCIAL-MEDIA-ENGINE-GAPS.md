# Remaining acceptance boundaries

## Fixed in the new public implementation
- Native Codex/Claude manifests and marketplace registration.
- Mandatory first-run onboarding, saved progress and approved brand brief.
- Portable, brand-separated memory instead of copied company defaults.
- Self-contained creative/editorial/review instructions without private skill paths.
- Hash-bound content/review approval, owner change-request invalidation and revision history.
- Explicit Postiz account/time/content consent, durable intents and no blind retries.
- Honest analytics provenance and unsupported-capability reporting.
- Local dashboard with real runtime actions, media previews and responsive layout.
- Minimal distributable without legacy application artifacts or licensed customer assets.
- Consistent English, Arabic and Japanese installation/usage documentation.

## Required before claiming a particular production deployment is verified
**P1 / External acceptance:** install and invoke through the user's actual Codex/Claude
account; validate live-provider capabilities with dedicated safe accounts; verify actual
publication, analytics and permission-specific engagement. Local tests cannot substitute
for account/app approvals.

**P1 / Creative acceptance:** a genuine owner must evaluate actual samples for their own
brand, approve useful feedback, and review revised outputs. Fictional technical fixtures
are not that approval and do not prove parity with an established production campaign.

**Product boundary:** a universal inbox, automatic social OAuth broker, automatic provider
analytics ingestion, hosted authentication/multi-user operation and unattended posting
are not bundled v1 features. The documentation no longer presents them as implemented.

**Repository history:** the new artifact excludes old content. Prior Git history is not
rewritten by this change. Repository owners should review historical content/licensing
before treating the entire historical checkout as a clean redistributable product.
Do not delete history or force-push without a separate explicit decision.
