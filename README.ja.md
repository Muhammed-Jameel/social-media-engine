## 小さなチームで、質の高い運用を

個人事業主、クリエイター、小規模チームなど、中規模の SNS 運用を少人数で
行う方に向けたプラグインです。汎用テンプレートではなく、ブランドの情報と
承認済みのルールから制作を始めます。

| 段階 | 提供する機能 |
| :--- | :--- |
| ブランド理解 | 中断・再開できる質問、ガイドライン、素材、声のトーン、目標 |
| 記憶 | ブランド別のプロフィール、権利情報、適用範囲付きのフィードバック |
| 計画 | 月次戦略、コンテンツの柱、ブリーフ、タイムゾーン付きの予定 |
| 制作 | プラットフォーム別文章、画像、カルーセル、動画の制作手順 |
| レビュー | ローカルダッシュボード、実ファイルの確認、修正履歴、承認 |
| 配信 | 承認済みコンテンツの書き出し、任意の Postiz 連携 |
| 学習 | 根拠付きの指標記録、分析手順、オーナーが承認した継続ルール |

**初期リリースはローカル型のエージェントプラグインです。**
ホスティングサービスや自動投稿ボットではありません。文章や企画は利用中の
ホストのモデルが生成します。画像・動画には利用可能な生成／レンダリング
ツールが必要です。モデル契約や外部サービスの利用料金は含まれません。

## 必要な環境

- プラグイン／スキルとローカル実行に対応した Codex または Claude。
- Python 3.10 以上と、IANA タイムゾーンデータベース。
- 書き込み可能な非公開の作業フォルダーと、使用権のあるブランド素材。
- 任意で画像・動画・デザインツール、Postiz のクラウドまたは自己ホスト環境。

タイムゾーンデータがない環境では、次を実行してください。

```sh
python -m pip install tzdata
```

必須の OpenAI API キーや特定の有料制作サービスはありません。

## インストール

### Codex

アプリのプラグイン／マーケットプレイス管理から次の GitHub リポジトリを追加し、
**Social Media Engine** を有効にします。

```text
Muhammed-Jameel/social-media-engine
```

組織によっては管理者による許可やインポートが必要です。画面と利用可否は
アカウント・アプリのバージョンによって異なります。
[OpenAI の案内](https://help.openai.com/en/articles/20001504)を参照してください。
Codex 用のマーケットプレイス定義とネイティブマニフェストを同梱しています。

### Claude Code

```text
/plugin marketplace add Muhammed-Jameel/social-media-engine
/plugin install social-media-engine@social-media-engine
```

呼び出しは `/social-media-engine:social-media-engine`、または自然言語で依頼します。
ローカル開発では次のように読み込めます。

```sh
claude --plugin-dir ./plugins/social-media-engine
```

### Claude Cowork

アカウントで利用できるプラグイン追加画面を使います。対応していれば GitHub
マーケットプレイスを追加し、そうでなければリリースのプラグイン専用 ZIP を
アップロードします。リポジトリ全体のソース ZIP はインストール用ではありません。

作業フォルダーへのアクセスを許可してください。実行環境には Python と
書き込み権限が必要です。ローカルサーバーのプレビューに対応しない場合は、
書き出したファイルをホストで確認します。

## 初回の進め方

次のように依頼してください。

> Social Media Engine でブランドを設定してください。作業フォルダーは
> [非公開フォルダー] です。必要な質問をし、ブランド資料を確認して、
> コンテンツ制作の前に私の承認を得てください。

1. 事業、商品・サービス、顧客、市場、言語、目標を共有します。
2. ガイドライン、ロゴ、ライセンスのあるフォント、参考例、禁止表現を渡します。
3. まとめられたブランドブリーフを確認・承認します。回答は途中でも保存されます。
4. 制作ツールと配信方法を選びます。Postiz は任意で、手動書き出しも可能です。
5. ツールが対応していれば、カルーセルと短い動画を含む 3〜5 件で品質を調整します。
6. 実際の出力に具体的なフィードバックを出し、継続したいルールだけ承認します。

ブランドごとに別の識別子を使います。日本語・アラビア語・英語など、制作言語は
README の翻訳ではなく、ブランドの設定で決まります。

## 依頼の例

| 目的 | 依頼例 |
| :--- | :--- |
| 月次計画 | 「目標とチームの作業量に合わせて来月を計画し、戦略を先に説明して」 |
| カルーセル | 「このアイデアを Instagram 用のカルーセルと Facebook 用の別案にして」 |
| 動画 | 「台本、絵コンテ、実際の動画ファイル、全編再生レビューまで制作して」 |
| レビュー | 「ダッシュボードを開き、承認が必要なものを見せて」 |
| 学習 | 「LinkedIn では大げさな表現を使わないルールを提案して」 |
| 納品 | 「承認した素材とキャプションを手動投稿用に書き出して」 |
| 予約 | 「送信前に投稿内容、アカウント、日時を正確に見せて」 |
| 分析 | 「この実データを分析し、取得できない指標と次の実験を示して」 |

## レビューダッシュボード

エージェントに起動を依頼するか、リポジトリで次を実行します。

```sh
python3 plugins/social-media-engine/scripts/sme.py \
  --workspace "/absolute/path/to/private-workspace" \
  --brand your-brand dashboard
```

表示された非公開 URL を同じ端末で開き、プロセスを動かしたままにします。
終了は Ctrl+C です。ブランド情報、素材、計画、実ファイル、レビュー、
フィードバック、承認、送信記録を確認できます。現在の画面は英語です。

127.0.0.1 とランダムなセッショントークンを使用します。URL を公開したり、
インターネットに公開したりしないでください。複数利用者向けの認証済み
ホストサービスではありません。

## 任意の Postiz 連携

自身の環境変数に設定します。実際のキーを会話に貼り付けないでください。

```text
POSTIZ_API_URL=https://your-postiz-instance.example/api/public/v1
POSTIZ_API_KEY=your-private-key
```

プロキシのパス接頭辞を含む、実際の公開 API ベース URL を指定してください。
例の値は使えません。また、プラグインは環境ファイルを自動読み込みしません。
接続済みアカウントを確認し、承認済み内容に紐づく送信計画を用意します。
送信にはユーザーの明示的な確認に加え、次の両方が必要です。

```text
--send
SOCIAL_ENGINE_ALLOW_PUBLISH=true
```

外部サービスに下書きを作成する場合も同様です。
**送信受付は公開完了ではありません。** 結果が不明な場合は再送せず、
プロバイダーの状態を確認して照合します。ローカルでのキャンセルは
Postiz 側の予約や公開済み投稿を削除しません。TikTok の UPLOAD モードでは
TikTok アプリ内で投稿を完了する操作が必要な場合があります。

Instagram、Facebook、TikTok を優先していますが、実際の自動投稿対応は
接続先、形式、アカウント資格、設定、権限に依存します。すべてのネットワークを
網羅する OAuth や統合受信箱はありません。コメント・DM・分析にはそれぞれ
対応するデータソースと権限が必要です。

## プライバシーと安全性

- データは作業フォルダーの `.social-media-engine/` に保存します。公開 Git から除外してください。
- ブランド・内容・適用ルールの変更で関連承認が無効になります。素材はハッシュで検査します。
- インストール時の自動通信や組み込みのテレメトリーはありません。
- 許可された外部ツールの利用時には、選択した素材や文章がそのサービスへ送られます。
- プラグイン自身はローカルデータを暗号化しません。端末とフォルダーを適切に保護してください。
- バックアップはダッシュボードと CLI を停止して状態フォルダー全体をコピーします。
- 実際の投稿、表現、権利、言語をオーナーが確認してください。品質や掲載承認を保証するものではありません。

## 開発・デプロイ

MIT ライセンスで改変・利用・ホスティングが可能です。ただし v1 が直接
サポートするのはローカルの単一オーナー運用です。公開サービスや複数ユーザー
運用には、認証、認可、隔離、秘密情報管理、バックアップ等の追加設計が必要です。

```sh
python3 -m unittest discover -s tests -v
python3 scripts/build_release.py
```

専用 ZIP と SHA-256 チェックサムは `dist/` に出力されます。非公開ブランド
データやローカルの旧実装アーカイブは含めません。テストが検証するのは
プログラムの動作であり、創作の好みや実アカウントの権限ではありません。
本番運用前に安全なテストアカウントで連携を確認してください。
