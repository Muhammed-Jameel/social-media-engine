# Iteration 03 — Document Before Automation

## Objective

Create a genuinely different Arabic-first post that teaches an operational prerequisite: an unclear process should be documented before it is automated.

## Exact copy

- Metadata: `مبدأ تشغيلي · ١٥`
- Headline line 1: `العملية الغامضة`
- Headline line 2: `لا تصلح للأتمتة`
- Support: `وثّق الخطوات أولًا، ثم أتمت ما يستحق التكرار.`
- Diagram labels: `قبل التوثيق` / `بعد التوثيق` / `وضوح`

## Concept tournament

1. **Selected — RTL process field:** irregular outlined modules on the right pass through one bright clarity corridor and become a strict documented system on the left. The diagram follows Arabic reading direction and makes structure carry meaning.
2. Rejected — another physical machine/object: the feed and Iterations 01–02 already contain enough object-led metaphor.
3. Rejected — checklist UI: too close to a dashboard screenshot and dependent on illegible microcopy.
4. Rejected — oversized headline only: strong at thumbnail scale but would not visibly demonstrate the learned modular principle.

## Research applied

- Structure is the primary visual language, with controlled detail saturation.
- Arabic typography and geometry form one layout system.
- Each module has a defined role; the grid is explanatory, not decorative.
- One continuous corridor guides the eye through the state change.

## Originality and asset record

The design is constructed entirely from native HTML/CSS, project Ghroob fonts, and the canonical AURENDOR logo. It contains no generated image, downloaded icon, external vector, stock photography, or professional reference pixels.

## Quality target

Every applicable critic must clear 145/160 with no hard fail at 1080×1350 and 324×405. Production remains paused.
