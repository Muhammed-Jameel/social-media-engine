# Social Media Engine
### كل ما يتعلق بوسائل التواصل الاجتماعي، في إضافة واحدة

إضافة للفرق الصغيرة وأصحاب المشاريع الفردية لإدارة المحتوى انطلاقًا من هوية علامتهم،
باستخدام Codex أو Claude.

[English](README.md) | **العربية** | [日本語](README.ja.md)

---

## ما الذي تقدمه الإضافة؟

| المرحلة | الوظيفة |
| :--- | :--- |
| فهم العلامة | استبيان قابل للاستكمال، جمهور، أهداف، أسلوب كتابة وأصول بصرية |
| الذاكرة | ملفات منفصلة للعلامات وقواعد معتمدة وملاحظات محددة النطاق |
| التخطيط | استراتيجية شهرية ومحاور محتوى ومواعيد مرتبطة بالمنطقة الزمنية |
| الإنتاج | إرشادات للكتابة والصور والمنشورات متعددة الشرائح والفيديو |
| المراجعة | لوحة محلية لمعاينة الملفات وتسجيل الملاحظات والموافقة |
| التسليم | تصدير يدوي أو إرسال اختياري عبر Postiz بعد تأكيد صريح |
| التعلم | سجلات مؤشرات موثقة وقواعد مستخلصة من ملاحظات المالك بعد موافقته |

**هذا الإصدار إضافة محلية، وليس خدمة مستضافة أو روبوت نشر تلقائي.**
ينفذ نموذج الذكاء الاصطناعي في التطبيق العمل الإبداعي. تحتاج الصور والفيديو إلى أدوات
إنتاج أو تصيير متاحة. لا تتضمن الإضافة اشتراكًا في نموذج أو رصيدًا للخدمات الخارجية.

## المتطلبات والتثبيت

تحتاج إلى Codex أو Claude يدعم الإضافات وتنفيذ الملفات المحلية، وPython 3.10 أو أحدث،
ومجلد عمل خاص قابل للكتابة. إذا كانت قاعدة المناطق الزمنية غير متاحة، يمكن تثبيت
حزمة tzdata باستخدام الأمر التالي:

</div>

```sh
python -m pip install tzdata
```

### Claude Cowork

استخدم واجهة إضافة الإضافات المتاحة لحسابك. أضف السوق من GitHub إذا كان الخيار
متاحًا، أو ارفع ملف ZIP المخصص للإضافة من إصدارات المشروع. ملف ZIP الخاص بمصدر
المستودع كاملًا ليس حزمة تثبيت الإضافة. امنح Cowork صلاحية الوصول إلى مجلد عملك.
إذا تعذر عرض خادم محلي داخل بيئة التطبيق، راجع الملفات المصدرة بدلًا من لوحة المتصفح.

## أول استخدام

اطلب من المساعد:

> استخدم Social Media Engine لإعداد علامتي. مجلد العمل هو [مجلد خاص بك].
> اسألني أسئلة التعريف، وراجع ملفات الهوية، واطلب موافقتي قبل إنتاج المحتوى.

1. عرّف النشاط والعروض والجمهور والأسواق واللغات والأهداف.
2. أضف ملفات الهوية والشعار والخطوط المرخصة والأمثلة والأساليب الممنوعة.
3. راجع ملخص العلامة واعتمده. تحفظ الإجابات تدريجيًا ويمكن استكمالها لاحقًا.
4. اختر أدوات الإنتاج والتسليم. Postiz اختياري، والتصدير اليدوي متاح.
5. اطلب 3 إلى 5 نماذج، بينها منشور متعدد الشرائح وفيديو إذا كانت الأدوات متاحة.
6. راجع الملفات الفعلية، وقدّم ملاحظات محددة، واعتمد القواعد التي تريد استمرارها.

لا تفترض الإضافة لهجة عربية معينة. تحدد أنت اللهجة والنبرة واللغات.
لكل علامة معرّف مستقل، ولا ينبغي خلط معلومات العلامات.

## لوحة المراجعة

اطلب فتح اللوحة، أو نفذ الأمر التالي من نسخة المستودع:

</div>

```sh
python3 plugins/social-media-engine/scripts/sme.py \
  --workspace "/absolute/path/to/private-workspace" \
  --brand your-brand dashboard
```

<div dir="rtl">

افتح الرابط الخاص الذي يظهر على الجهاز نفسه واترك العملية تعمل. استخدم Ctrl+C
للإيقاف. تتضمن اللوحة الهوية والأصول وخطط المحتوى ومعاينات الملفات والملاحظات
والموافقات وسجلات الإرسال والأدلة. واجهة اللوحة الحالية باللغة الإنجليزية.

ترتبط اللوحة بالعنوان المحلي 127.0.0.1 وتستخدم رمز جلسة عشوائيًا. لا تنشر الرابط
ولا تعرض الخادم للإنترنت. هذه ليست خدمة آمنة متعددة المستخدمين.

## النشر عبر Postiz

هيئ بيانات خدمتك الخاصة في بيئة التنفيذ، وليس داخل المحادثة:

</div>

```text
POSTIZ_API_URL=https://your-postiz-instance.example/api/public/v1
POSTIZ_API_KEY=your-private-key
```

<div dir="rtl">

استخدم عنوان واجهة API العامة الفعلي لخدمتك مع أي بادئة لمسار الوكيل.
هذه أمثلة وليست بيانات اتصال فعلية. لا تقرأ الإضافة ملفات البيئة تلقائيًا.
تتحقق من الحسابات المتصلة، ثم تجهز عملية مرتبطة بالمحتوى والحساب والوقت.
يتطلب الإرسال موافقة صريحة وخياري الأمان التاليين، حتى لإنشاء مسودة بعيدة:

</div>

```text
--send
SOCIAL_ENGINE_ALLOW_PUBLISH=true
```

<div dir="rtl">

الاستجابة الناجحة للإرسال لا تثبت أن المنشور أصبح عامًا. عند غموض النتيجة،
تحقق من حالة المزود بدلًا من إعادة المحاولة تلقائيًا. إلغاء عملية محلية لا يلغي
منشورًا أو جدولًا لدى Postiz. قد يتطلب وضع الرفع في TikTok إكمال النشر داخل التطبيق.

إنستغرام وفيسبوك وTikTok أهداف أساسية، لكن الدعم الفعلي يعتمد على الحساب
والمزود والصيغة والصلاحيات. لا تتضمن الإضافة صندوق رسائل موحدًا لكل الشبكات.
تحتاج التعليقات والرسائل والتحليلات إلى مصادر وصلاحيات متاحة فعلًا.

## الخصوصية والنسخ الاحتياطي

تُحفظ البيانات داخل المجلد التالي في مساحة عملك:

</div>

```text
.social-media-engine/
```

<div dir="rtl">

استبعده من المستودعات العامة. لا توجد اتصالات تلقائية عند التثبيت أو قياس استخدام
مضمّن. قد تُرسل الملفات المختارة إلى أدوات خارجية عند الاستخدام المصرح به.
البيانات المحلية ليست مشفرة بواسطة الإضافة. استخدم حماية الجهاز ومجلدات موثوقة.
انسخ مجلد الحالة كاملًا بعد إيقاف اللوحة والأوامر، ولا تدمج قواعد البيانات يدويًا.

التغييرات في الهوية والقواعد والمحتوى تُبطل الموافقات المتأثرة. يتحقق النظام
من سلامة الملفات ومن شروط المراجعة، لكنه لا يضمن جودة كل مخرج أو قبول المنصة له.
